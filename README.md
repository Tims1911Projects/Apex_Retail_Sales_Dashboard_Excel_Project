# 📊 APEX Retail Sales Dashboard | Microsoft Excel

## 📌 Project Overview

The **APEX Retail Sales Dashboard** is an interactive Microsoft Excel data analytics project designed to provide a comprehensive overview of retail sales performance.

The dashboard transforms sales data into meaningful visual insights, allowing users to monitor key performance indicators (KPIs), evaluate sales trends, compare regional performance, and analyze product categories and payment methods.

This project demonstrates how Microsoft Excel can be used to organize, analyze, and visualize business data to support informed decision-making.

## 📈 Key Performance Indicators (KPIs)

The dashboard provides three primary performance indicators:

- 💰 **Total Sales:** 93,859
- 📊 **Total Profit:** 15,256
- 📦 **Total Quantity Sold:** 260

These KPIs provide a quick snapshot of overall business performance.

## 🔎 Dashboard Features

### 🎛️ 1. Interactive Filters (Slicers)

Users can interact with the dashboard using filters to explore sales performance across different business segments.

- 🌎 **Region:** East, North, South, and West
- 🛍️ **Product Category:** Clothing, Electronics, Furniture, Home Decor, Others, and Sports
- 💳 **Payment Mode:** Card, Cash, and Online

### 🏷️ 2. Profit by Category

A pie chart visualizes profit distribution across product categories, helping identify which product segments contribute to overall profitability.

### 📉 3. Sales Trend Analysis

A line chart displays sales activity over time, providing visibility into sales fluctuations and trends throughout the reporting period.

### 🏆 4. Top 5 Salespersons

A horizontal bar chart compares the performance of the five leading sales representatives based on sales.

### 💳 5. Quantity by Payment Mode

A column chart compares transaction quantities across Card, Cash, and Online payment methods.

### 🌎 6. Sales by Region

A column chart compares sales performance across the four geographic regions, helping identify stronger and weaker sales markets.
